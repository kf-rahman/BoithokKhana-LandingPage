# Archive — the order app

These stories, specs and the PR checklist belong to the online order app
(FastAPI + Postgres + Claude order parsing + a Next.js order form and admin
dashboard) that this repo used to contain. It was removed in October 2026;
orders come in on WhatsApp and Messenger instead.

They're kept because they're a readable record of how that app was specified,
not because anything here is still true. Nothing in them describes the live
site — that's `index.html`, and `CLAUDE.md` describes it.

The code itself is in git history and on the `workflow-1`, `workflow2` and
`workflow3` branches.
