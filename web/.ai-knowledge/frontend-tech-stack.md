# Frontend Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Testing:** Jest + React Testing Library (or Vitest — confirm on
  project init; update this file once decided)

## Commands

```
npm run dev          # dev server, :3000
npm run build
npm run type-check
npm test
```
